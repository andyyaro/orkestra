# Orkestra

> Coordinate many agents. Deliver one verified result.

Orkestra is an open-source, local-first orchestration runtime that lets two
or more autonomous coding agents (Claude Code, OpenAI Codex CLI, Google
Gemini CLI, and your own adapters) collaborate on the same software project
with minimal human intervention.
