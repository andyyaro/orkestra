# orkestra

Open source · PyPI · Multi-agent coding runtime

## Files

| Folder | File | Use it for |
|---|---|---|
| `lockup/` | `lockup-color.svg/.png` | The full logo on its brand background (#F2EEE6) |
| `lockup/` | `lockup-black.svg/.png` | One-colour logo, transparent background, for light backgrounds |
| `lockup/` | `lockup-white.svg/.png` | One-colour logo, transparent background, for dark backgrounds |
| `mark/` | `mark-color.svg/.png` | The symbol alone in colour, transparent; made for its brand background |
| `mark/` | `mark-black.svg/.png`, `mark-white.svg/.png` | The symbol alone in one colour, transparent |
| `icons/` | `icon-square.svg`, `icon-1024.png`, `icon-512.png`, `icon-192.png` | App stores and web-app manifests (square; the platform rounds the corners) |
| `icons/` | `icon-rounded.svg` | Places that show the icon as-is (READMEs, slides, profile pictures) |
| `icons/` | `apple-touch-icon.png` (180 px) | iPhone and iPad home-screen bookmark |
| `icons/` | `favicon.svg`, `favicon.ico`, `favicon-32.png`, `favicon-16.png` | Browser tab icon |
|  | `logo-sheet.png` | The presentation sheet from the design canvas |

The wordmark text in every SVG is already converted to shapes, so the files look the same without the font installed.
PNG lockups are 2400 px wide and marks 1024 px square; the SVGs scale to any size.
